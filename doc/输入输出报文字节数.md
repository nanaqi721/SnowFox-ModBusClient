下面以“上位机发送请求、下位机返回响应”为方向，列出常用 Modbus RTU 读写功能码的报文结构和总字节数。

所有长度都包含：

```
从站地址 + 功能码 + 数据 + CRC
```

字段规则：

- 从站地址：1字节
- 功能码：1字节
- 寄存器地址：2字节，高字节在前
- 寄存器数量：2字节，高字节在前
- CRC：2字节，低字节在前
- 一个寄存器：2字节
- 8个线圈最多占1字节

假设：

```
N = 读取或写入的数量
B = 线圈数据字节数 = (N + 7) / 8
```

## 一、读取线圈 `0x01`

读取可读写的线圈状态。

### 上位机发送

```
[从站地址 1]
[功能码 01 1]
[起始地址 2]
[线圈数量 2]
[CRC 2]
```

总长度：

```
1 + 1 + 2 + 2 + 2 = 8字节
```

示例结构：

```
01 01 00 00 00 0A CRC_L CRC_H
```

表示从1号从站的地址0开始读取10个线圈。

### 下位机响应

```
[从站地址 1]
[功能码 01 1]
[字节数量 1]
[线圈数据 B]
[CRC 2]
```

总长度：

```
5 + (N + 7) / 8
```

读取10个线圈：

```
B = (10 + 7) / 8 = 2字节
响应长度 = 5 + 2 = 7字节
```

响应结构：

```
01 01 02 Data1 Data2 CRC_L CRC_H
```

每个数据字节中的最低位表示地址较小的线圈。

## 二、读取离散输入 `0x02`

读取只读的开关量输入。

报文结构与 `0x01` 完全相同，只是功能码变成 `02`。

### 上位机发送

```
[地址 1][02 1][起始地址 2][数量 2][CRC 2]
```

总长度：

```
8字节
```

### 下位机响应

```
[地址 1][02 1][字节数 1][数据 B][CRC 2]
```

总长度：

```
5 + (N + 7) / 8
```

## 三、读取保持寄存器 `0x03`

读取可读写的16位保持寄存器。

### 上位机发送

```
[地址 1]
[功能码 03 1]
[起始地址 2]
[寄存器数量 2]
[CRC 2]
```

总长度固定为：

```
8字节
```

示例：

```
01 03 00 00 00 02 CRC_L CRC_H
```

表示读取两个保持寄存器。

### 下位机响应

```
[地址 1]
[功能码 03 1]
[数据字节数 1]
[寄存器数据 N×2]
[CRC 2]
```

总长度：

```
5 + N * 2
```

如果读取两个寄存器：

```
01 03 04 00 0A 00 14 CRC_L CRC_H
```

总长度：

```
1 + 1 + 1 + 4 + 2 = 9字节
```

其中：

```
00 0A = 第一个寄存器，数值10
00 14 = 第二个寄存器，数值20
```

## 四、读取输入寄存器 `0x04`

读取只读的16位输入寄存器。

报文结构与 `0x03` 相同，只是功能码为 `04`。

### 上位机发送

```
[地址 1][04 1][起始地址 2][数量 2][CRC 2]
```

总长度：

```
8字节
```

### 下位机响应

```
[地址 1][04 1][字节数 1][寄存器数据 N×2][CRC 2]
```

总长度：

```
5 + N * 2
```

## 五、写单个线圈 `0x05`

### 上位机发送

```
[地址 1]
[功能码 05 1]
[线圈地址 2]
[写入值 2]
[CRC 2]
```

总长度：

```
8字节
```

线圈值只能是：

```
FF 00 = ON
00 00 = OFF
```

例如：

```
01 05 00 03 FF 00 CRC_L CRC_H
```

表示把1号从站地址3的线圈设置为 ON。

### 下位机响应

正常情况下，下位机原样返回请求：

```
01 05 00 03 FF 00 CRC_L CRC_H
```

总长度：

```
8字节
```

上位机应检查返回的地址和值是否与请求一致。

## 六、写单个保持寄存器 `0x06`

### 上位机发送

```
[地址 1]
[功能码 06 1]
[寄存器地址 2]
[写入值 2]
[CRC 2]
```

总长度：

```
8字节
```

例如向地址1写入数值100：

```
01 06 00 01 00 64 CRC_L CRC_H
```

### 下位机响应

下位机原样返回请求：

```
01 06 00 01 00 64 CRC_L CRC_H
```

总长度：

```
8字节
```

## 七、写多个线圈 `0x0F`

`0x0F` 是十进制功能码15。

### 上位机发送

```
[地址 1]
[功能码 0F 1]
[起始地址 2]
[线圈数量 2]
[数据字节数 1]
[线圈数据 B]
[CRC 2]
```

总长度：

```
9 + (N + 7) / 8
```

例如写入10个线圈：

```
B = (10 + 7) / 8 = 2
总长度 = 9 + 2 = 11字节
```

报文结构：

```
01 0F 00 00 00 0A 02 Data1 Data2 CRC_L CRC_H
```

### 下位机响应

```
[地址 1]
[功能码 0F 1]
[起始地址 2]
[实际写入数量 2]
[CRC 2]
```

总长度：

```
8字节
```

响应结构：

```
01 0F 00 00 00 0A CRC_L CRC_H
```

响应不会返回全部线圈数据，只返回起始地址和写入数量。

## 八、写多个保持寄存器 `0x10`

`0x10` 是十进制功能码16。

### 上位机发送

```
[地址 1]
[功能码 10 1]
[起始地址 2]
[寄存器数量 2]
[数据字节数 1]
[寄存器数据 N×2]
[CRC 2]
```

总长度：

```
9 + N * 2
```

例如写两个寄存器，值分别为10和20：

```
01 10 00 00 00 02 04 00 0A 00 14 CRC_L CRC_H
```

总长度：

```
1 + 1 + 2 + 2 + 1 + 4 + 2 = 13字节
```

其中：

```
00 02 = 写入两个寄存器
04    = 后面有4个数据字节
00 0A = 数值10
00 14 = 数值20
```

### 下位机响应

```
[地址 1]
[功能码 10 1]
[起始地址 2]
[实际写入数量 2]
[CRC 2]
```

总长度：

```
8字节
```

响应结构：

```
01 10 00 00 00 02 CRC_L CRC_H
```

## 常用功能汇总

| 功能码 | 功能           | 请求长度      | 正常响应长度  |
| ------ | -------------- | ------------- | ------------- |
| `0x01` | 读取线圈       | 8             | `5 + (N+7)/8` |
| `0x02` | 读取离散输入   | 8             | `5 + (N+7)/8` |
| `0x03` | 读取保持寄存器 | 8             | `5 + N×2`     |
| `0x04` | 读取输入寄存器 | 8             | `5 + N×2`     |
| `0x05` | 写单个线圈     | 8             | 8             |
| `0x06` | 写单个寄存器   | 8             | 8             |
| `0x0F` | 写多个线圈     | `9 + (N+7)/8` | 8             |
| `0x10` | 写多个寄存器   | `9 + N×2`     | 8             |

这里的除法是整数除法：

```
int coilByteCount = (quantity + 7) / 8;
```

## 异常响应

所有功能码的异常响应长度都是5字节：

```
[从站地址 1]
[请求功能码 | 0x80 1]
[异常码 1]
[CRC 2]
```

总长度：

```
5字节
```

例如读取保持寄存器 `0x03` 发生“非法数据地址”：

```
01 83 02 CRC_L CRC_H
```

其中：

```
83 = 03 | 80
02 = 非法数据地址
```

因此你的 `ReadResponse()` 需要特殊处理异常响应：即使正常响应预计是几十个字节，只要功能码最高位为 `1`，就只读取5字节。

另外，广播地址 `0` 只适用于写操作。下位机收到广播写请求后执行操作，但不会返回响应。
